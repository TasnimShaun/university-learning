Experiment 2: Widget Components (Required Experiment, Verification Experiment, 2 Academic Hours)

Experiment Objectives
Gain proficiency in using scroll views, progress bars, seek bars, rating components, image views, image buttons, switch components, grid views, and labels.

Experiment Contents
Implement the following programs on the computer: Using scroll views, image views, image buttons, labels, and grid views.

Experiment Requirements
(1) Master the methods of designing android programs.
(2) Learn to comprehensively use multiple components and layout design to create complex interfaces.
