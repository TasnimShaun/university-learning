【Experiment 1】: Familiarization with Android Development Environment (Required Experiment, Validation Experiment, 2 Class Hours)

Experiment Objectives
Gain familiarity with the components, configuration, and functionality of the Android development environment.
Experiment Details
(1) Refer to the textbook and observe the structure of the Android SDK.
(2) Create an Android Project and set up a virtual device.
(3) Run a pre-built Android sample and observe the results.
Experiment Requirements
(1) Be proficient in operating the Android program development environment.
(2) Familiarize oneself with the methods and functions of creating virtual devices.
